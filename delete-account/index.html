Delete Your AccountKonto löschen

This page works without the app installed and without an existing session — it verifies you directly, then triggers the same real, server-side deletion the app itself uses. Diese Seite funktioniert ohne installierte App und ohne bestehende Sitzung — sie verifiziert dich direkt und löst dieselbe echte, serverseitige Löschung aus, die auch die App selbst nutzt.

How this worksSo funktioniert es

  1. 1

    Verify it's you

    Identität bestätigen

    Sign in below with your MoneyLive email and password — the same credentials you use in the app. This page never sees or stores your password; it's sent straight to Supabase (our auth provider) to obtain a one-time session token.

    Melde dich unten mit deiner MoneyLive-E-Mail und deinem Passwort an — denselben Zugangsdaten wie in der App. Diese Seite sieht oder speichert dein Passwort nicht; es wird direkt an Supabase (unseren Auth-Anbieter) gesendet, um ein einmaliges Sitzungs-Token zu erhalten.

  2. 2

    Confirm deletion

    Löschung bestätigen

    You'll be asked to explicitly confirm — this cannot be undone.

    Du wirst gebeten, ausdrücklich zu bestätigen — dies kann nicht rückgängig gemacht werden.

  3. 3

    Server-side deletion

    Serverseitige Löschung

    Your session token is sent to our account-deletion service, which verifies it directly with Supabase and then permanently deletes your auth.users record. Your profile and leaderboard entry are removed automatically as a consequence (database cascade) — no separate step, nothing left behind.

    Dein Sitzungs-Token wird an unseren Konto-Löschdienst gesendet, der es direkt bei Supabase verifiziert und anschließend deinen auth.users-Datensatz dauerhaft löscht. Dein Profil und dein Bestenlisten-Eintrag werden dadurch automatisch entfernt (Datenbank-Kaskade) — kein separater Schritt, nichts bleibt zurück.

  4. 4

    Done

    Fertig

    You'll see a confirmation on this page. Your login no longer works, anywhere.

    Du siehst eine Bestätigung auf dieser Seite. Deine Zugangsdaten funktionieren danach nirgendwo mehr.

Request deletionLöschung anfragen

Needs backend configuration The account-deletion service (a Cloudflare Worker — code already in the repo at server/account-delete) has not been deployed with a public URL configured on this page yet. The self-service form below is disabled until that URL is set — see assets/js/delete-account.js. This is not faked as working. Backend-Konfiguration ausstehend Der Konto-Löschdienst (ein Cloudflare Worker — Code bereits im Repository unter server/account-delete) wurde noch nicht mit einer auf dieser Seite hinterlegten öffentlichen URL bereitgestellt. Das Selbstbedienungsformular unten ist deaktiviert, bis diese URL gesetzt ist — siehe assets/js/delete-account.js. Dies wird nicht fälschlich als funktionsfähig dargestellt.

Prefer email?Lieber per E-Mail? You can always request deletion by emailing khodrtalal@gmail.com from the address on your account. We'll verify it's you and delete the account manually, normally within a few days. Du kannst die Löschung jederzeit per E-Mail an khodrtalal@gmail.com von der mit deinem Konto verknüpften Adresse anfragen. Wir verifizieren dich und löschen das Konto manuell, in der Regel innerhalb weniger Tage.
